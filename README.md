# MoodPulse • Real-Time Face Mood Reader & Adaptive Workspace

A clean, human-centered Web ML application designed for real-world use with an adaptive workspace, real-time facial expression analysis, active calibration, and 60-second breathing breaks.

---

## 🚀 Quick & Simple Start

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the Application
In your terminal:
```bash
python app.py
```
*(On Windows, you can also double-click **`run.bat`** or run **`run.ps1`**)*

### 3. Open in Browser
Visit:
👉 **`http://localhost:5000`**

Create a new account on the **Sign Up** page, or sign in to your existing account.

---

## 🌟 Key Features

1. **🔐 Secure User Login**:
   - Encrypted password hashing with `bcrypt`.
   - Protected user sessions and isolated personal history.

2. **📹 Instant Mood Check-in**:
   - Click **▶ Start Check-in** to track your facial expressions in real time.
   - Automatically adapts workspace colors and ambient recommendations to how you feel.

3. **💾 Permanent History & Feedback**:
   - Click **💾 Record This Mood** or tap **✓ Yes, accurate!** / any mood chip.
   - Saves your check-ins with timestamps directly to the database.

4. **🫁 60-Second Breathing Reset**:
   - Built-in 4-4-4 box breathing guide for quick stress and fatigue relief.
